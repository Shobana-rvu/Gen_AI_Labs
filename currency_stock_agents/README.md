Country Currency & Stock Market Agent
An AI-powered Streamlit application built using LangChain + Groq LLM that provides:

Official currency of a country
Real-time exchange rate to USD, INR, GBP, EUR
Major stock exchanges & indices
Live index values (Yahoo Finance)
Google Maps location of stock exchange HQ
🚀 Live Demo
🔗 Streamlit App: https://genailabs-hcjkfirwuwyztpa7osh6nm.streamlit.app

🛠 Tech Stack
Frontend: Streamlit
LLM Framework: LangChain
LLM Engine: LLaMA3 via Groq
Financial Data: Yahoo Finance (yfinance)
Exchange Rates: ExchangeRate-API
Maps: Google Maps Embed
Language: Python
📌 Features
✅ Displays official currency of selected country
✅ Fetches real-time exchange rates
✅ Retrieves live stock index values
✅ Lists major stock exchanges
✅ Displays Google Maps pin of stock exchange HQ
✅ Uses LangChain-integrated LLM
